# CHMAYCO M.2 B-key SATA 焊盘补料与验证指南

- 作者：Codex（AI 助手）
- 生成时间：2026-11-22
- 背景：CHMAYCO GS-DR01 主板预留未焊接的 M.2 B-key 焊盘。软件已预埋为 `sata1`，本指南记录补料和首次上电验证方法。
- 适用仓库与分支：`rk3588_livedeck_chmayco`，`main`
- 适用硬件：QZ8809/QZ8801 RK3588 主板，实物带 `5G` 丝印和 `256+16` 标签
- 软件基线：Armbian `edge`，Linux 7.3；vendor 6.1 同步启用
- 资料依据：实物照片、PADS 网表、原厂 5.10 DTB。PADS 索引有 `89.PCIE-M.2(option)`，但当前 ASCII 导出不含第 89 页正文。

## 结论

该焊盘是 67 pin、0.5 mm 间距的 M.2 B-key SMT 座焊盘。SATA 目标只支持 B+M key NGFF SATA SSD，不支持常见 M-key NVMe SSD。

优先补装：

| 项目 | 数量 | 建议规格 | 说明 |
| --- | ---: | --- | --- |
| M.2 B-key 座 | 1 | 67 pin，0.5 mm 间距，卧式 SMT，常见 4.2 mm 高度 | 必须与焊盘、定位柱和固定脚尺寸一致 |
| 串联交流耦合电容 | 4 | 100 nF，X7R，16 V 或更高，封装按焊盘实测 | 通常为 0201；用于 `SATA30_1_TX/RX` 四根差分线 |
| 3.3 V 去耦电容 | 已贴装 | 照片右侧两颗大封装电容已贴装 | 先量测，不重复补料 |
| `DEVSLP` 下拉电阻 | 0 或 1 | 10 kΩ，封装按焊盘实测 | 仅当第 38 脚没有板上下拉且网络未接 GND 时补装 |

不要为纯 SATA 方案补装以下 PCIe 专用料：

- `REFCLK_P/N` 时钟耦合或端接。
- `PERST#`、`WAKE#`、`CLKREQ#` 上拉或下拉。
- PCIe 指示灯和 LED 限流电阻。

不要把 5 V 接到 M.2 座的 3.3 V 电源脚。B-key SATA 盘只使用 3.3 V。

## 焊盘拓扑

```text
                   板边
      +----------------------------------+
      |  pin 1                           |
      |  [B-key 上排触点]  [key gap]     |
      |  [B-key 下排触点]                |
      |         C   C   C   C            |
      |         |   |   |   |            |
      |      SATA差分线交流耦合           |
      |                                  |
      +----------+          +------------+
                 |  3.3 V   |
              [大电容]    [大电容]
```

照片中两颗大封装电容已有焊料。四颗小串联电容位为空，分别跨在四根高速差分线上。

## 连接器选型

选件必须满足以下条件：

1. B-key 缺口在左侧，实物丝印为 `5G`。
2. 67 pin，0.5 mm 触点间距。
3. 卧式 SMT，固定脚和定位柱与现有焊盘重合。
4. 高度与原板结构空间一致。常见值为 4.2 mm，但以实物装配高度为准。
5. 触点镀金，支持至少 1.5 A 的 3.3 V 供电。

核对连接器时先打印 1:1 焊盘图，并检查以下尺寸：

- 两端固定脚中心距。
- 两个定位孔直径与中心距。
- 首末触点跨度。
- 触点排距和缺口位置。

## 装配步骤

1. 断电并拆下主板电池或断开所有电源。
2. 用显微镜检查焊盘是否平整。清除氧化、残锡和助焊剂。
3. 给连接器固定脚和定位区域少量助焊剂。
4. 先对齐定位柱和两端固定脚，再检查每个触点是否居中对齐。
5. 固定两端。使用热风从 PCB 背面预热，避免板翘。
6. 逐段焊接触点。0.5 mm 间距下不要用拖焊跨越多个脚。
7. 清洗助焊剂，在显微镜下检查桥连、偏位和虚焊。
8. 补装四颗 100 nF 串联电容。确认封装方向不影响差分线阻抗。
9. 若第 38 脚没有下拉，补装 10 kΩ 到 GND。

## 首次上电检查

先不要插 SSD：

1. 测量 M.2 座所有 3.3 V 脚对 GND 的电阻。读数不能接近 0 Ω。
2. 上电后测量 3.3 V 脚，应为 3.1 至 3.5 V。
3. 测量 `DEVSLP`。不支持 DevSleep 时应为低电平。
4. 测量 `SATA30_1_TXP/N` 和 `SATA30_1_RXP/N`，不能对地短路。
5. 断电后插入 B+M key SATA SSD。

## U-Boot 验证

在 U-Boot 命令行执行：

```text
scsi scan
scsi info
part list scsi 0
```

期望识别一个 SCSI 设备。若没有设备：

1. 检查连接器焊接。
2. 检查四颗交流耦合电容。
3. 检查 3.3 V 和 `DEVSLP`。
4. 检查 U-Boot 是否包含 `AHCI`、`DWC_AHCI`、`SCSI` 和 `CMD_SCSI`。

## Linux 验证

```bash
cat /proc/device-tree/sata@fe220000/status
cat /proc/device-tree/pcie@fe170000/status
dmesg | grep -Ei 'ahci|ata[0-9]|scsi'
lsblk -o NAME,SIZE,TRAN,MODEL
```

期望：

- `sata@fe220000/status` 为 `okay`。
- `pcie@fe170000/status` 为 `disabled`。
- 出现 `fe220000.sata`、SATA link up 和 `/dev/sdX`。
- `lsblk` 的 `TRAN` 显示 `sata`。

## 验收条件

只有同时满足以下条件，才能判定硬件补料通过：

1. 连接器无短路和虚焊。
2. 3.3 V 电压和电流余量正常。
3. U-Boot 能执行 `scsi scan` 并识别磁盘。
4. Linux 能建立 SATA1 link 并枚举块设备。
5. USB、TF、M.2 SATA、eMMC 的顺序启动不破坏现有启动链。
